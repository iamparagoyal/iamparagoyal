## 🚀 Featured Project

<h3 align="center">✨ Fireflies — Meeting Notes & Transcription Workspace</h3>

<p align="center">
  <a href="https://github.com/iamparagoyal/fireflies"><img src="https://img.shields.io/badge/Repository-181717?style=flat-square&logo=github&logoColor=white" alt="View repository" /></a>
  &nbsp;
  <a href="https://fireflies0.vercel.app"><img src="https://img.shields.io/badge/Live%20Demo-7c3aed?style=flat-square&logo=vercel&logoColor=white" alt="Live demo" /></a>

A full-stack meeting workspace for exploring transcripts, summaries, action items, and meeting insights.

**Highlights**
- 📝 Transcript viewer with synchronized timestamps and search.
- ✅ Action-item management and meeting summaries.
- 🔎 Full-text search across meeting transcripts.
- 🤖 Optional AI-powered notes and question answering.
- 🧱 Next.js + TypeScript frontend with a FastAPI backend.
